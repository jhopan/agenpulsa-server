Channel Publik (Testimoni) tanpa nomor HP

Transaksi sukses dikirim ke topik PUBLIK (bisa dibaca orang lain) — tanpa nomor HP, ref, dan data pribadi.
Boleh pakai bot yang sama dengan admin (kosongkan token publik) — cukup beda chat ID + topik. Isi token sendiri kalau mau bot testimoni terpisah.

Supergroup mode forum? Isi Topik Testimoni dengan message_thread_id supaya notif masuk topik tertentu, bukan general. Cari nilainya: kirim pesan di topik itu, lalu buka https://api.telegram.org/bot<TOKEN>/getUpdates → cari "message_thread_id".

Bot lain juga bisa kirim ke topik ini: POST /api/v1/notify-public dengan {"pesan":"..."} (nomor HP otomatis dibuang).

Cara dapatkan cookies

  1. Login ke isipulsaBuka `isipulsa.web.id` di Chrome atau Edge pada HP/PC sendiri, lalu login seperti biasa.
  2. Pasang Cookie-EditorCari ekstensi Cookie-Editor di Chrome Web Store atau Edge Add-ons, lalu pasang.
  3. Export cookiesKembali ke tab isipulsa. Buka Cookie-Editor, pilih Export, lalu salin JSON atau simpan file `.json`.
  4. Masukkan di halaman iniPilih Upload File untuk file JSON, atau paste JSON ke kolom bawah.
  5. Inject CookiesTekan tombol Inject Cookies. Setelah sukses, cek status akun di atas.

Panduan Telegram

  1. Buat botBuka @BotFather di Telegram. Kirim `/newbot`, lalu ikuti langkah sampai menerima token bot.
  2. Simpan tokenPaste token ke kolom Bot token pada halaman ini.
  3. Ambil ID TelegramBuka @userinfobot, kirim pesan apa saja, lalu salin nilai ID yang ditampilkan.
  4. Simpan pengaturanPaste ID ke kolom ID Telegram admin, lalu tekan Simpan Pengaturan.
  5. Aktifkan dan tesKirim `/start` ke bot yang dibuat, kemudian tekan Tes Notif.

Kirim ke Topik Supergrup

  1. Jadikan grup SupergrupBuka grup → Settings → ubah jadi Supergroup. Setelah itu aktifkan Topics (mode forum).
  2. Buat topikBuat topik baru, misal "Testimoni". Semua pesan transaksi akan masuk ke topik ini.
  3. Tambahkan bot ke grupAdd bot testimoni ke supergrup, lalu jadikan Admin (minimal izin kirim pesan). Tanpa admin, bot tidak bisa posting.
  4. Ambil chat IDKirim satu pesan di topik Testimoni (misal "tes"). Lalu buka:
    https://api.telegram.org/bot<TOKEN>/getUpdates
    Cari "chat":{"id":-100xxxxxxxxxx} → itu chat ID supergrup. Isi ke kolom Chat / channel tujuan.
  5. Ambil message_thread_idDi respons getUpdates yang sama, cari "message_thread_id":12 (angka topik). Isi ke kolom Topik Testimoni.
  6. Simpan & tesTekan Simpan Pengaturan, lalu buat satu transaksi uji. Notif harus muncul di topik Testimoni, bukan di General.

Kalau notif muncul di General: berarti message_thread_id kosong/salah. Ambil ulang dari getUpdates setelah kirim pesan di dalam topik (bukan di General).

Kalau error "not enough rights" / "chat not found": bot belum jadi admin, atau chat ID salah (pakai ID supergrup -100..., bukan ID user).

Bot lain juga bisa kirim ke topik ini:
POST /api/v1/notify-public body {"pesan":"..."} dengan header X-API-Key. Nomor HP/ref otomatis dibuang sebelum dikirim.

Panduan Webhook

  1. Pastikan URL server publikIsi URL server pada bagian Integrasi, lalu Simpan Pengaturan.
  2. Salin URL webhookTekan Copy di samping URL webhook.
  3. Tambahkan di PaypanBuka admin Paypan, masuk ke Konfigurasi lalu Webhook, kemudian Tambah.
  4. Paste dan simpanPaste URL tadi sebagai endpoint webhook, lalu simpan.
  5. Pastikan secret samaNilai Paypan secret pada AgenPulsa harus sama dengan webhook secret yang digunakan Paypan.
